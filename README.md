# Account Management System - Vue 3 Test Project for SaaSoft

Система управления учетными записями, реализованная в рамках тестового задания для SaaSoft.

## 📋 Описание проекта

Приложение представляет собой форму управления учетными записями с возможностью добавления, редактирования и удаления записей. Поддерживает два типа учетных записей: LDAP и локальные, с соответствующей логикой отображения полей.

## 🛠 Технологический стек

- **Vue.js 3** - фреймворк с использованием Composition API
- **TypeScript** - типизированный JavaScript
- **Pinia** - современный стейт-менеджер для Vue
- **Vite** - инструмент сборки
- **UI Framework** - Naive UI

## 📊 Модель данных

### Типы учетных записей

```typescript
export type AccountType = "LDAP" | "Local";

export interface AccountLabel {
  text: string;
}

export interface Account {
  id: string;
  label: string;
  labels?: AccountLabel[];
  accountType: AccountType;
  login: string;
  password: string | null;
}
```

## ✨ Функциональность

### Основные возможности

- ✅ **Добавление учетных записей** - кнопка "+" для создания новой записи
- ✅ **Удаление учетных записей** - кнопка удаления для каждой записи
- ✅ **Валидация полей** - проверка обязательных полей с визуальной индикацией ошибок
- ✅ **Автосохранение** - сохранение данных при потере фокуса/изменении значений
- ✅ **Персистентность** - сохранение данных в localStorage через Pinia

### Поля учетной записи

#### 1. Метка (Labels)

- **Тип**: Необязательное поле
- **Ограничения**: Максимум 50 символов
- **Формат**: Текстовые метки через разделитель ";"
- **Обработка**: Преобразуется в массив объектов `{ text: string }`

#### 2. Тип записи (Account Type)

- **Тип**: Выпадающий список (обязательное поле)
- **Варианты**:
  - `LDAP` - скрывает поле "Пароль", сохраняет password как null
  - `Локальная` - показывает поле "Пароль"

#### 3. Логин (Login)

- **Тип**: Текстовое поле (обязательное)
- **Ограничения**: Максимум 100 символов

#### 4. Пароль (Password)

- **Тип**: Текстовое поле (условно обязательное)
- **Ограничения**: Максимум 100 символов
- **Логика**: Отображается только для типа "Локальная"

## 🔄 Логика работы

### Жизненный цикл учетной записи

1. **Создание**: Нажатие кнопки "+" добавляет пустую запись в конец списка
2. **Редактирование**: Изменение полей запускает валидацию
3. **Валидация**:
   - Для текстовых полей - при потере фокуса
   - Для селекта - при изменении значения
   - Невалидные поля отмечаются красной обводкой
4. **Сохранение**: Валидные записи автоматически сохраняются в store
5. **Удаление**: Кнопка удаления полностью удаляет запись

### Правила валидации

- **Логин**: Обязательное поле, не более 100 символов
- **Тип записи**: Обязательное поле
- **Пароль**: Обязательное для типа "Локальная", игнорируется для "LDAP"
- **Метка**: Необязательное, не более 50 символов

## 🎯 Особенности реализации

### Управление состоянием

- Использование Pinia для централизованного управления состоянием
- Автоматическое сохранение в localStorage
- Восстановление данных при перезагрузке страницы

### Обработка меток

Метки обрабатываются специальным образом:

```typescript
// Ввод: "метка1;метка2;метка3"
// Результат: [{ text: "метка1" }, { text: "метка2" }, { text: "метка3" }]
```

### Условная логика полей

- Поле пароля динамически показывается/скрывается в зависимости от типа записи
- Для LDAP записей пароль автоматически устанавливается в `null`
